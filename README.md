# Goosebot: Self-Driving Robot Car
This repository contains the mode and implementation script files for the Goosebot project for
our Autonomous Robotic Vehicles course (EEL4660) at Florida Polytechnic University <br>

* [Click here for Video Demonstration](https://drive.google.com/file/d/1CsQ0IuaXm-ntTdOesSkDJeHTemNeDtV9/view?usp=sharing) of the Goosebot running three laps under 60 seconds <br>
* [Click here for Report File](https://github.com/techyam08/goosebot-project/tree/main/final_report) to obtain detailed information on setup and implementation steps.

The following files were adopted from [this reference repository](https://github.com/hoanbklucky/goose] for intial implementation and troubleshooting
* detect.py
* drive.py

And the following file was written to support keyboard control of the goosebot while running the first trained AI model (best_rknn_model:
* combined_code_goose.py

The code files involved in the final version of the Goosebot, as shown in the demo video above, are the following:
* best_goose_rknn_model directory
* test_drive_v3.py
